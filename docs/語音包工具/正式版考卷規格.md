# N5 模擬考（正式版）考卷規格

`docs/n5-mock-full.html` 的考卷怎麼做。**做新的一份（B 卷、C 卷）就照這份走。**
2026-10-11 定案，A 卷是照這份做出來的參考實作。

---

## 0. 四個檔案與順序

| 檔案 | 做什麼 |
|---|---|
| `paper_lib.py` | 共用樣板：helper、聴解播放結構、正解打散、檢查、寫檔 |
| `paper_X.py` | 考卷的**原始檔**，只寫題目內容 → 產出 `docs/data/paper-X.json` |
| `build_mockfull.py` | 把 JSON 嵌進 `n5-mock-full.html`（三份考卷一起掃） |
| `mockfull_audio.py` | 產聴解音檔到 `docs/audio/mockfull/`，寫 say 對照表 |
| `audit_paper.py X` | 體檢：撞題、圖片、音檔、唸法、文章與空格 |
| `test_mockfull.mjs` | 流程與計分的端對端驗證 |

```
python3 paper_B.py && python3 build_mockfull.py && python3 mockfull_audio.py \
  && python3 audit_paper.py B && node test_mockfull.mjs
```

**改題目一律從 `paper_X.py` 改**，不要去改 JSON 或 HTML —— 下一次 build 會蓋掉。

## 2. 計分

兩個得分區分（N5 只有兩個，不是三個）：

| 区分 | 題數 | 滿分 | 基準分 |
|---|---|---|---|
| 言語知識（文字・語彙・文法）・読解 | 43 | 120 | 38 |
| 聴解 | 24 | 60 | 19 |

- 分數 = `round(答對題數 × 滿分 ÷ 題數)`，兩區分各自四捨五入再相加。
- 合格 = **總分 ≥80 且兩個區分都 ≥ 基準分**。
- 正式考試用 IRT 尺度得点，複製不了，畫面上要標「參考分數」。

## 3. 題目本身的規矩

- **題目與選項都固定、不洗牌**。換裝置、重考幾次都要是同一份 —— 所以順序在 `paper_X.py` 產檔時就排好。
- **正解位置要打散**：`paper_X.py` 結尾會自動把正解輪流放到第 1→2→3→4 格（圖片題與組み立て題除外），不用手動安排。產完看一下分布，不能有某一格特別少。
- **不能和簡易考（`n5-mock-easy.html`）撞題**，台詞也不行。`audit_paper.py` 會比對。
  - 例外：JLPT 的制式題幹（「何と 言いますか。」「男の人は これから 何を しますか。」…）本來就會一直重複，不算撞題。
  - 例外：あいさつ類的選項（「ありがとう ございます。」…）是固定說法，也不算。
- **一份考卷裡同一張圖只能用一次**，例題的圖也不能和正式題的圖相同。跨卷可以重複用同一張圖，
  但題目、對話、選項都要不一樣。
- **唸出來的「選項」可以重複**（あいさつ、決まり文句 本來就是固定說法）；不能重複的是
  **題幹、旁白與對話**。`audit_paper.py` 就是照這條判的。
- 制式題幹（「何と 言いますか。」「女の人は これから 何を しますか。」…）正式考試本來就一直重複用，
  不算撞題；清單在 `audit_paper.py` 的 `BOILER`。

### 文章長度（不含分詞空白）

| 大題 | 字數 | 結構 |
|---|---|---|
| 問題3 文章の文法 | 250〜270 | 一篇，四個空格標 `【1】`〜`【4】`，四題的題幹就是 `【n】` |
| 問題4 短文 | 70〜90 | 兩篇，各一題 |
| 問題5 中文 | 250〜270 | 一篇，兩題 |
| 問題6 情報検索 | 200〜240 | 告示或表格，要有 `※` 的注意事項（答案常藏在這裡） |

### 解說的規格（比簡易考更詳細）

| 題型 | 一定要寫到 |
|---|---|
| 文字語彙 | 正解的意思＋其他三個選項各自的意思＋**「容易選錯的地方」** |
| 文法 | 句型的形式與意思＋為什麼其他三個接不上＋**同類句型的對照** |
| 読解 | 其他選項錯在哪（沒提到／被否定掉）＋**「答案在哪一句」** |
| 聴解 | **關鍵句用 `<b>` 標出來**＋其他選項為什麼是陷阱（最常見的是「被否定掉的前一個方案」「現在的位置 vs 等一下要去的地方」） |

文章要附 `passZh` 全文翻譯，聴解要附 `zh` 對話翻譯（兩個都是交卷後才顯示）。

## 4. 聴解的播放規格

### 順序

```
これから、ちょうかいしけんを はじめます。…        （開頭總說明）
  └ 停 1.5 秒
問題1では、はじめに しつもんを 聞いて…           （大題說明，印出來的字和唸的是同一串）
  └ 停 2 秒
れい。→ 例題 → いちばん いい ものは ○ばんです。
  └ 停 2.5 秒
1ばん。→ 問題文 → 〔看圖／看選項的留白〕→ 会話 → 問題文 → 〔作答空檔〕
2ばん。…
（四個大題跑完）
これで ちょうかいしけんを おわります。            （結束語）
```

### 秒數

| 項目 | 問題1 | 問題2 | 問題3 | 問題4 |
|---|---|---|---|---|
| 唸完問題後的留白（看圖／看選項） | 5 秒 | **12 秒** | — | — |
| 作答空檔 | 10 秒 | 10 秒 | 8 秒 | 8 秒 |

常數在 `paper_X.py` 的 `GAP12 / GAP34` 與 `C1()` 的 `look`；頁面的段落停頓在 `n5-mock-full.html` 的 `P_OPENING / P_INSTR / P_EX`。

### 對話長度

- **問題1・2：每題 5 個來回**，而且要是完整句子（有 そうですか／じゃ 這種承接詞、有情境資訊），不是兩句話就結束。
- 被否定掉的干擾項**要真的唸出來**（「会社ですか」→「いいえ」），不能只存在於選項裡。
- 參考值：問題1 每題約 51 秒、問題2 約 53 秒、問題3 約 22 秒、問題4 約 18 秒；**全長 18 分鐘上下**。
  （正式考試的 30 分鐘包含考場說明與收發卷，實際音檔約 21〜25 分鐘。）

### 例題

四個大題**每一個都要有**，而且畫面上要有例題卡：有圖、有選項、**直接標出答案**、標「例題・不計分」。不列入計分，詳解頁也不顯示。

### 圖片

- 問題1 課題理解：四格圖（`img`，選項固定 `['1','2','3','4']`，`a` = 格號 − 1）
- 問題2 ポイント理解：**文字選項**，不用圖
- 問題3 発話表現：場景圖（`scene`），箭頭指的人要說話
- 問題4 即時応答：沒有圖

圖放 `docs/img/mock/`。寫題目前先去 `n5-mock-easy.html` 的題庫看那張圖的四格各是什麼（解說裡有寫），不要憑空猜。

### 語速與唸法

- `mockfull_audio.py` 的 `SPEED = 0.85`（VOICEVOX 預設 1.0 太快，這個值接近 JLPT 的播報）。
- 引擎會唸錯的字放 `READ_FIX`，合成前換成假名，**clip 的 key 仍用原文**（前端是用原文查的）。**順序有意義**：
  - `('何ですか','なんですか')` 要排在 `('何で','なにで')` 前面
  - `('日本語','にほんご')` 要排在 `('日本','にほん')` 前面（否則變「にほん語」）
  - `('十分','じゅっぷん')` —— 本頁的「十分」都是十分鐘，不是「足夠」
- 改了 `READ_FIX` 之後，**受影響的舊 clip 要手動刪掉**（id 是 `md5(speaker|原文)`，不會因為換唸法而改變，工具會以為已經有了）。

## 5. 其他規則

- 考試中**重新整理或關掉分頁 → 該份作廢**，歷史紀錄留一筆「未完成」。
- 聴解**不顯示倒數**，顯示「第 n 題 / 24」與進度條，音檔播完由使用者自己按交卷。
- 考試中不能重聽；**詳解可以單題重聽**。
- 歷史紀錄存 localStorage `mf_hist_<卷號>`，每卷最多 20 筆。

---

## 6. 做新考卷的步驟

1. 複製 `paper_A.py` 成 `paper_B.py`，改最後一行 `paper('B', 'B 卷', ...)` 與 `OUT` 的檔名。
   （helper 都在 `paper_lib.py`，不用重抄。）
2. 換掉全部 67 題（文章、對白、選項、解說）。聴解的圖從 `docs/img/mock/` 裡挑**沒被 A 卷用過**的。
3. `python3 paper_B.py` → 看題數 67、正解位置分布平均。
4. `python3 build_mockfull.py`（頁面的選卷頁會自動多一張卡，不用改 HTML）。
5. `python3 mockfull_audio.py` → 產音檔。
6. `python3 audit_paper.py B` → 要「沒有發現問題」。
7. `node test_mockfull.mjs` → 全部 PASS。
